# Hugging Face benchmark results

Keep retained `hf-reference benchmark` JSON results in this directory. The
result itself records the corpus and tokenizer hashes, fixed encoding mode,
warm-up and measurement iteration counts, requested thread count, OS,
architecture, available parallelism, and a required free-form environment
description.

Use the environment field to record at least the CPU/model, OS version, power
mode, and any relevant process-affinity or background-load constraints. Use a
distinct result file for every tokenizer, corpus, machine, thread count, or
benchmark configuration. Do not overwrite or combine materially different
runs, and do not present a smoke run as a performance result.

Benchmark JSON is not generated by `make generate-fixtures`; measurements are
explicit and machine-specific. Review results before committing them.
