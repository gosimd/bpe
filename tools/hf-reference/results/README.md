# Hugging Face benchmark results

Keep retained `hf-reference benchmark` JSON results and CPU profiles in this
directory. A benchmark result records the corpus, oracle, tokenizer, vocabulary,
merges, tool-source, and lockfile hashes; fixed encoding mode; warm-up and
measurement counts; requested thread count; OS; architecture; available
parallelism; and a required free-form environment description.

Use the environment field to record at least the CPU/model, OS version, power
mode, and any relevant process-affinity or background-load constraints. Use a
distinct result file for every tokenizer, corpus, machine, thread count, or
benchmark configuration. Do not overwrite or combine materially different
runs, and do not present a smoke run as a performance result.

Benchmark JSON is not generated by `make generate-fixtures`; measurements are
explicit and machine-specific. Each result contains four separate cases:
pre-tokenization only, BPE only with its cache disabled at construction, full
encode with that uncached model, and full encode after prefilling the upstream
default cache. Do not estimate BPE time by subtracting the pre-tokenizer result
from full encode, and do not compare throughput without checking whether the
byte denominator is source text or transformed BPE pieces.

For a retained profile, keep the raw profiler output and a short Markdown
report that records the profiled operation, profiler command and sampling
interval. Treat sample counts as evidence about hot call paths, not exact
stage timings. Review all result files before committing them.

## Historical workload notice

The retained `gpt2-wikitext2-*` reports measure the retired WikiText-2 validation
corpus, not the current English train pool. Their commands require the original
source revision and inputs; timings and metadata have not been relabeled.

## Current multilingual baseline

`bpe-multilingual-2026-09-10/` holds the four HF modes for each of the four
models and five current language pools. See the
[Go/HF BPE comparison and workload report](../../../benchmarks/results/bpe-multilingual-2026-09-10/README.md)
for conditions and limits. Only uncached BPE is compared there; these files
are not a claim that the Go tokenizer supports every full pipeline.
